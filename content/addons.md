# Included sources and optional tools

Use this page for source/add-on questions, not as another coding workflow.
Unified Engineering is one instruction-only plugin with 30 coordinated skills.
Its sources are combined methods, not independent routers that must all run.

## Core integration

| Source | Contribution | Treatment |
|---|---|---|
| Ponytail | Simplicity, reuse, audits, debt and benchmark reports | Adapted material; three report skill files preserved unchanged |
| Superpowers | Planning, implementation, debugging, testing and delivery | Adapted and coordinated workflows |
| Addy Osmani Agent Skills | Focused engineering expertise | Selected specialist methods/references |
| Matt Pocock Skills | Domain terms, module design, prototypes and handoffs | Selected adapted methods |
| Karpathy-inspired community guidelines | Assumptions, scoped changes and verifiable goals | Independently worded conceptual influence; not authored by Karpathy |

Four collections contribute copied/adapted material with retained notices. The
Karpathy-inspired source contributes ideas only; its text is not redistributed.

## Additional conceptual influences

- Visual critique: Impeccable, UI UX Pro Max, Taste Skill, Front-End-Checklist
  and Emil Kowalski Skills informed our visual-review/motion reference.
- Security: Cloudflare informed audit-evidence methods; ECC informed skill/plugin
  intake checks. Their complete auditing/scanning runtimes are not included.
- Diagrams: Archify and Diagram Design informed our source-backed diagram method.
- Evaluation: Anthropic Skills informed our comparison/evidence guidance.

These ten sources informed five independently authored references introduced in
0.3. Their original text, executables, hooks, assets and services are not bundled.
Use the relevant specialist only when the task calls for it. The addon/source
inventory itself is help, not another specialist or required startup step.

## Tools versus methods

The package does not configure Claude-Mem/MemPalace, REA, Graphify,
Understand-Anything, Firecrawl, Agent-Reach, Browser Use, AgentShield,
Orca, Paperclip or OpenDesign. It does not provide automatic transcript capture,
background memory, lifecycle hooks or telemetry. The host may separately expose
tools/plugins; do not claim they are installed or absent account-wide from this
package inventory. Optional integrations need their own supported setup and
actual user authorization.

## Explain versions accurately

Distinguish the installed plugin, a source branch and a downloadable release.
Changing GitHub does not update an installed ChatGPT plugin. Read actual installed
metadata when exposed; if it is unavailable, distinguish a user's reported version
from a verified version rather than infer one from a GitHub tag or old context.

Static archive checks, cloud file access, automatic routing and Android UI tests
prove different things. Report only the observed checks for the actual version.
Do not equate an included method with an installed external tool or promise
runtime compatibility merely because its reference can be read.
