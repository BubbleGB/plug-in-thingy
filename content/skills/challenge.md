# Challenge the artifact, then stop when resolved

{{POLICY}}

Define the claim being scrutinized and isolate the smallest useful artifact plus its contract. Include evidence/callers necessary to judge it; strip the author's persuasive narrative. Request concrete counterexamples, missing assumptions and violations of the contract, not generic approval.

Fresh-context review requires a real supported agent with appropriate context controls. Use it only when authorized and permitted. Otherwise perform a clearly labeled self-review or provide a review brief for the user; do not pretend the review is independent. External/cross-model review requires explicit authorization and real tools, never an automatic offer/install cycle.

Read every finding against the actual artifact. Classify it as a contract misunderstanding, actionable defect, accepted trade-off or noise. Correct the contract/evidence when missing context caused confusion. Do not accept a finding merely because another agent asserted it.

Start with one bounded pass. Repeat only for a substantive changed artifact or unresolved material finding; stop when remaining findings are trivial, duplicates or explicitly accepted trade-offs. After at most three substantive cycles, summarize the unresolved issue rather than loop indefinitely. A different model is optional, not a universal quality guarantee.

For a reusable review brief use [the adversarial template](references/adversarial-review.md). Report the review's actual independence, evidence and limitations, without leaking unrelated source or session content.
