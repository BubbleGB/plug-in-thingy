implicit activation, invocation-policy enforcement and actual Android operation
are not verified. Existing plugins remain installed; no application repository
was changed. The 0.1.0 archives are retained for rollback.

## Practical acceptance still required

Upload the plugin ZIP through the supported account flow, inspect all 30 registry
entries and their references, test a routine edit, report-only assessment,
prototype and nontrivial fix, and verify behavior in the real Android Codex flow.
Use an isolated supported context for standalone results without removing the
working plugins. If other routers are active, disclose that limitation. Do not
promise the new plugin can override their instructions or persist settings
globally. Replace old installations only after testing and explicit instruction.
