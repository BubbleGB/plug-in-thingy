# Unified Engineering v0.3.1

Engineering help can now explain the included sources/add-ons and distinguish
adapted methods, conceptual influences and external tools. It also distinguishes
an installed plugin from a GitHub source or release version. The listing credits
all four adapted source collections.

The builder rejects reference filename collisions and conflicting section
selections. Archive inspection checks the packaged reference hashes and legacy
local hashes rather than accepting silently changed guidance. Original source
hashes remain available, and failed verification preserves the previous good ZIP.

31 package tests pass, including four regression tests reproduced before fixing
the defects. Ten sampled installed v0.3.0 resources matched that release in an
actual cloud readback. Version 0.3.1 still needs its own upload and Android task
acceptance; no automatic update or measured outcome/token gain is claimed.

The same 30 skills, source notices and preserved Ponytail files remain. No extra
runtime, external scanner, memory service or hook is installed.

Use **unified-engineering-0.3.1.zip** for plugin upload. The source ZIP is for
maintenance. Keep your previous working ZIP for rollback. See
