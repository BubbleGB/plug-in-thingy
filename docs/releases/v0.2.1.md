# Unified Engineering v0.2.1

30 coordinated, instruction-only engineering skills with Full/Lite/Ultra modes.

This patch validates invocation metadata and manual-only flags, rejects skill
folders missing their entry, reports malformed UTF-8 references and clarifies
manual-only cloud discovery. The 24-test suite passes, and the source rebuilds
the plugin ZIP byte-for-byte on the same Python/zlib implementation.

The initial repository launch adds CI, contributor/maintainer documentation and
release automation around the unchanged plugin payload. Its SHA-256 remains:

## Which file to download

- `unified-engineering-0.2.1.zip`: the single-plugin upload artifact.
- `unified-engineering-source-0.2.1.zip`: complete authoring source, for maintenance.
- `SHA256SUMS.txt`: verify both archives.

The installed 0.2.0 package's 30 skills and 95 Markdown files were confirmed
readable through the cloud API. That evidence does not certify 0.2.1 installation,
Android UI or universal automatic routing. Keep working plugins until this
release passes the actual target workflow. No hooks or background services are
required. This is a test prerelease, not a public ChatGPT directory submission.
