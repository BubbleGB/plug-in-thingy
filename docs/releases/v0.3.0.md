# Unified Engineering v0.3.0

The existing 30 skills now have focused references for visual critique and motion,
traceable security-audit evidence, skill/plugin intake review, source-backed
system diagrams and skill evaluation. Relevant specialists can use these methods
without a new router, required dependency or repeated development lifecycle.

The package builder hashes local references, prevents unsafe local-reference
paths/symlinks and enforces the listing subtitle limit. Existing source inputs,
four original notices and three preserved Ponytail skill files remain intact.

The source repository also retains the GitHub survey and its counts/source data,
and corrects links to BubbleGB/plug-in-thingy.

Validation: 27 package tests, ZIP inspection/CRC, provenance checks, official
portable manifest schema and independent YAML parsing passed locally. Fresh model
trials were blocked by CLI authentication; managed upload and Android runtime
acceptance of 0.3.0 remain unverified. No token savings or measured behavior gain
is claimed. See [the evidence](../VALIDATION-0.3.md).

Use unified-engineering-0.3.0.zip for plugin upload. Source ZIPs are maintenance
artifacts. Existing working plugins were not updated or removed. Earlier local
archives remain available for rollback.
