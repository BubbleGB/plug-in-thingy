# Unified Engineering 0.3.0 evidence

Local candidate release, 17 November 2026. This version has not been uploaded or
installed in managed ChatGPT. No Android task trial or fresh successful model
comparison was performed. Existing installations and original branches remain
available; no application repository was touched.

## Delivered change

The same 30 entry points, 24 eligible for automatic matching and six manual-only.
Discovery descriptions, common policy, modes, pinned inputs and the three original
Ponytail audit/debt/gain skill files are unchanged.

Five independently authored references enrich frontend, security, architecture,
docs and skill-authoring. Their subjects are visual critique/motion, audit
evidence, instruction/package intake, source-backed diagrams and evaluation.
Seven new packaged reference destinations share those five maintained files.
Ten reviewed conceptual sources have immutable revisions and reviewed-file
hashes in content/influences.json and the package's SOURCES.json. None of their
original text, scripts, hooks or assets was imported into the plugin.

The builder now records the hashes of all 13 local reference destinations.
It rejects absolute/traversing names, symlinks and nonregular local references
before copying them, and checks the 30-character subtitle limit. The existing
subtitle was shortened. Source tests remain standard-library-only.

## Behavior evidence and blocked checks

Fourteen positive, negative and pressure scenarios were defined before changing
the guidance, including brand preservation, RTL, interrupted motion, suspicious
and benign imports, confirmed/blocked/partial audits, source/proposal diagrams,
memory limits, measurement claims and unrelated small work.

The unmodified 0.2.1 guidance and subject prompt were saved for a fresh baseline
trial. The first CLI evaluation failed before producing any model response:
"Your access token could not be refreshed because you have since logged out or
signed in to another account. Please sign in again."

No fallback model, account change or successful trial is claimed. There are zero
completed baseline samples and zero candidate samples for this release. The
scenarios are prospective fixtures, not a passing behavior suite. The verification
record in tests/results/research-0.3.json contains prompt/evidence hashes and
this limitation. Historical 0.1/0.2 trials are not reused as proof of changed text.

Package checks and manual scope review are useful evidence, but do not establish
native routing, outcome improvements, token savings or managed-host compatibility.
The previous 0.2.0 cloud listing/resource evidence remains historical evidence for
that installed version only.
